# GuestGuide — Casa Mare (demo)

Este paquete contiene una página estática lista para publicar con GitHub Pages.

## Publicación

1. Inicia sesión en GitHub y crea un repositorio nuevo llamado `guestguide-casa-mare`.
2. Para que GitHub Pages pueda publicar el sitio, configura el repositorio como público (el código será visible).
3. Sube `index.html` a la raíz del repositorio.
4. Abre **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**.
6. Selecciona la rama `main` y la carpeta `/(root)`, y pulsa **Save**.
7. Espera a que termine la publicación. La URL aparecerá en la sección Pages y tendrá un formato parecido a `https://TU-USUARIO.github.io/guestguide-casa-mare/`.

## Antes de usarla con huéspedes

- Sustituye el nombre, fotos, dirección, horarios y recomendaciones por información real y confirmada.
- Cambia el contacto ficticio por el canal autorizado del anfitrión.
- Comprueba la página en un móvil y prueba el selector ES/EN.
- No publiques códigos de cerraduras, contraseñas privadas, datos personales ni instrucciones de acceso sensibles en una página pública.
- La demo usa fotografías remotas de Unsplash; necesitará conexión a Internet para mostrarlas.

## Crear una guía para otro alojamiento

Duplica el repositorio o el archivo `index.html`, cambia los contenidos y publica cada alojamiento en su propio repositorio/ruta. Mantén una hoja privada separada con los datos de cada cliente.
